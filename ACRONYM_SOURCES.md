## Domain Coverage

The acronym database is organized across 5 official Security+ exam domains:

1. **Domain 1.0 - General Security Concepts** (12% weight)
   - Foundational security principles, cryptography basics, authentication models

2. **Domain 2.0 - Threats, Vulnerabilities, and Mitigations** (23% weight)
   - Attack types, vulnerability assessment, mitigation strategies

3. **Domain 3.0 - Security Architecture** (21% weight)
   - Network design, access control, identity management, encryption implementation

4. **Domain 4.0 - Security Operations** (16% weight)
   - Monitoring, incident response, compliance activities, security controls

5. **Domain 5.0 - Security Program Management and Oversight** (28% weight)
   - Risk management, business continuity, governance, compliance frameworks
